# Security Policy

## Supported Versions

This repository is in active early development (`0.3.x`). Security fixes are applied directly to `main`.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities (such as auth bypasses, path traversal, SSRF, or XML/HTML injection).

Instead, please contact the maintainer privately via GitHub Security Advisories (**Security -> Advisories -> Report a vulnerability**) or email `tonny.0955@gmail.com` with:
- A concise description of the issue and impact
- Minimal reproduction steps or proof-of-concept
- Any suggested fix if you have one

We will acknowledge receipt and work on a fix promptly before disclosing publicly.
