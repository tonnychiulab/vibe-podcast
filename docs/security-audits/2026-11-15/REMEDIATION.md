## Additional Hardening & Deferred Item Fixes

- **Deferred ledger unit `vibe_podcast/scriptwriter.py#extract_json`**: Replaced backtracking markdown fence regex with linear `_iter_fenced_blocks()` scanning, input slice limit (`250_000` chars), and bounded `raw_decode` probing (`_EXTRACT_JSON_MAX_PROBES = 20`).
- **Timing-safe UTF-8 token matching & clickjacking defense**: Encoded operands to UTF-8 before `hmac.compare_digest` in `_match_token_role()` (`auth.py`) so non-ASCII tokens cleanly return HTTP `401` rather than raising `TypeError`, and added `frame-ancestors 'none'` to CSP.
- **Report loading & filesystem hardening**: Caught `ValueError` in `server._resolve_report_path()` (returning HTTP `400`), added a 2 MiB size check in `MarkdownDirConnector.load_text()`, made `timeline.json` writes atomic in `synthesizer._finalize_synthesis()`, and added per-episode `episode_lock()` across `resynthesize_turn()` and `delete_episode()`.
- **TTS & RSS resilience**: Added per-turn `asyncio.wait_for(..., timeout=45.0)` + overall synthesis deadline in Edge-TTS synthesis, stripped XML 1.0 illegal ASCII control chars in `episodes_to_rss_xml()`, initialized browser `state.userRole` to `null`, mapped subprocess timeouts/errors cleanly in turn routes, and pinned `permissions: contents: read` + `uv sync --locked --extra dev` in [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml).
