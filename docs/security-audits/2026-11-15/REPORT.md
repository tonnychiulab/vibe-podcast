## 2. Security Posture Summary

Overall source-level engineering security posture is **thoughtful and substantially hardened**, with strong baseline controls around dual-role authentication (`SESSION_TOKEN` vs `LISTEN_TOKEN`, constant-time `hmac.compare_digest`, `0o600` token files, `HttpOnly`/`SameSite=Lax` cookies, strict `listener` `GET`/`HEAD` route allowlists), SSRF protections on `WebUrlConnector` (public-IP filtering, DNS IP pinning, redirect validation, `Content-Type` allowlist, 512 KB cap), symlink/path-containment checks (`MarkdownDirConnector`, `_resolve_episode_dir`), strict `escapeHtml()` + `Content-Security-Policy` + `X-Frame-Options: DENY` in the browser UI, randomized `<source_document_*>` XML wrappers, `shell=False` subprocess argv lists, and SHA256-pinned dependencies in `uv.lock`.

This `quick` audit recorded **0 confirmed** findings (because target-controlled runtime reproduction was blocked on this host), **9 `needs_validation` leads**, **0 rejected** claims, and **21 non-finding hardening notes**. The 9 leads needing local sandboxed or deployment validation concentrate around: (1) invoking headless `agy -p` on untrusted web/PDF content without disabling agent tools; (2) `show_memory` persisting LLM-generated episode summaries into `timeline.json` and re-injecting them outside `<source_document_*>` tags; (3) `vibevoice_remote` omitting DNS pinning, redirect checks, and response byte caps; (4) persistent Admin `SESSION_TOKEN` exposure via `GET /?token=` query strings and startup `logger.info`/access logs; and (5) resource-exhaustion gaps in `POST /api/generate/stream` semaphore/thread cleanup, unbounded `PodcastScript` turns/text/focus_questions, `pypdf -> pdftotext` fail-open stdout buffering, and `WebUrlConnector._http_get_bytes` slow-trickle reads.

## 6. Positive Source Patterns & Non-Finding Hardening Notes

### Positive Controls Verified in Source
- **Dual-role RBAC & Browser Isolation**: `vibe_podcast/auth.py` separates `admin` (`SESSION_TOKEN`) and `listener` (`LISTEN_TOKEN`) via `hmac.compare_digest`, restricts listeners to read-only playback/RSS/timeline routes, blocks admin query tokens on `/audio` and `/feed.xml` (`allow_query_admin=False`), sets `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, and `CSP default-src 'self'; script-src 'self'`, and stores no tokens in `localStorage`.
- **Outbound Web SSRF Controls**: `WebUrlConnector` (`vibe_podcast/connectors.py:187-333`) validates public IPs (including IPv4-mapped IPv6, link-local, loopback, CGNAT), pins resolved IPs via `_PinnedHTTPConnection`/`_PinnedHTTPSConnection`, re-validates up to 3 redirects via `_SafeRedirectHandler`, restricts `Content-Type`, and enforces a `512_000`-byte read cap.
- **Filesystem Containment & Atomic Writes**: `MarkdownDirConnector` (`vibe_podcast/connectors.py`) and `_resolve_episode_dir` (`vibe_podcast/routes/episodes.py`) reject symlinks and enforce `.resolve().is_relative_to(...)`; `show_memory.py` and `interview.py` use `tempfile.mkstemp` + `os.replace`.
- **UI Rendering & Supply Chain**: `web/js/state.js` (`escapeHtml`) escapes dynamic DOM insertions cleanly; `uv.lock` pins third-party wheels to PyPI/pythonhosted with SHA256 hashes.
